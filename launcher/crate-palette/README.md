# Crate Palette

A command palette for Ryoku's Super+Space, part of Crate for Ryoku. One field
searches your apps, your files, the files you opened recently and your Crate
library.

- A normal search lists apps, files and recent files first, then Crate's best
  artist, album and track.
- Type `cr ` (or press Tab until CRATE) to search Crate alone: artists, albums in
  a cover grid, and tracks with their length.
- Enter opens an app or file and plays a Crate result. Shift+Enter opens the
  result in Crate. Alt+Enter adds it to the queue when the Crate app offers that.
- Tab cycles ALL, APPS, FILES, CRATE and REC. Escape closes.

Crate results need the Crate desktop app running; when it is not, the palette
offers to start it. Covers and artist photos come from the app's local cache,
never from the network.

It follows the active Ryoku colour scheme, and the Crate theme's style switches
(accent marks, navigation font) when the running Ryoku has them.
